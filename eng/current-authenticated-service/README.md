# Current authenticated service consumer

This disposable exact-local package consumer proves the bounded W30 hosted
service transport. It restores `Runic.Application.Hosting` from the local
candidate feed, installs its tiny local npm client from a packed archive, then
exercises the C#-owned encrypted-cookie session, sanitized session projection,
same-origin antiforgery command, role denial, malformed/expired admission
denial, bearer rejection, and controlled shutdown twice with isolated caches.

It is not an identity-provider, HTTPS-deployment, SSR, CORS, WebSocket, or
browser-end-to-end proof. The temporary HTTP listener exists only to exercise
the package contract; the production profile remains the single HTTPS origin
and C# OIDC authorization-code admission defined by D008.
